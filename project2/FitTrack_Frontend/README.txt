FITTRACK FRONTEND PROTOTYPE

1. Extract this ZIP.
2. Copy the FitTrack_Frontend folder to C:\\xampp\\htdocs\\fittrack (or rename it to fittrack).
3. Start Apache in XAMPP. MySQL is not needed yet.
4. Open http://localhost/fittrack/index.html

Includes login/register demo, dashboard, workout tracker, tutorials, goals, progress/history, responsive CSS, and logout confirmation. This is frontend-only: authentication and data are temporary browser-session demos, not database-backed. Tutorial buttons are placeholders for video links.
